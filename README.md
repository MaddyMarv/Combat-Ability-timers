### [Ability Timer](https://www.nexusmods.com/warhammer40kdarktide/mods/673)
<img width="835" height="795" alt="image" src="https://github.com/user-attachments/assets/beea4ace-3101-4ebf-9553-3c0a01e5542e" />

Standalone mod that adds a clean timer to your HUD that counts down the exact duration of your active ability. Sometimes it's hard to tell when your ability is going to run out in the middle of a horde. It works for all classes and takes the guesswork out of timing your pushes and dodges.

**Options:**
  - Display mode [Timer + progress bar, Progress bar only, Timer only]
  - Show Options (bracket, bubble health %)
  - Default Bar & Text Colors
  - Use progress color toggles (Bar, Text)
  - High, Mid, Low Duration Colors
  - Track cooldown toggle
  - Cooldown display mode [Smooth (start from remaining), Full (show complete cooldown)]
  - Cooldown Color
  - Use Scrier's Gaze Bar
  - Static Peril Color
  - Use progress color (Scrier's Gaze)
  - Peril Colors (Low, High)
  - Show ability charges
  - Always show charges (even at 1 or 0)
  - Gauge Options (Length, Thickness)
  - Opacity
  - Orientation [Horizontal, Vertical]
  - Bar direction [Start, End, Center]
  - X/Y offset Options (Bar, Timer, Charges, Bubble Health)
  - Text alignment [Left, Center, Right]
  - Text size
  - Track Specific Abilities & Buffs
